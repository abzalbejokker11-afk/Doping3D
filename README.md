# Antidoping Portal — GitHub Pages uchun tayyor

## Ichida nima bor?
- `index.html` — portalning to'liq fayli (barcha rasmlar, stil va skriptlar ichida, boshqa fayl kerak emas)

## GitHub'ga yuklash tartibi

1. GitHub'da yangi repository yarating (masalan: `antidoping-portal`)
2. Ushbu zip'ni oching, ichidagi `index.html` faylini repo **root** (asosiy) papkasiga yuklang
   - GitHub sayti orqali: repo sahifasida **"Add file" → "Upload files"** tugmasi → `index.html`ni tashlang → **Commit changes**
3. **Settings → Pages** bo'limiga o'ting
4. "Branch" qismida `main` ni tanlang, papka: `/ (root)` → **Save**
5. 1-2 daqiqa kuting — sizga link beriladi: `https://username.github.io/antidoping-portal/`

## Muhim eslatma
Fayl nomi albatta **index.html** bo'lishi kerak — aks holda GitHub Pages sahifani ochmaydi.
